# 🌅 Thought of the Day

> One fresh motivational thought every morning — with its meaning, the author's name, and a beautiful card you can download and share.

---

## ✨ About

**Thought of the Day** shows a new thought automatically each day, picked by the date so everyone sees the same thought on the same day. Every thought comes with a short meaning, so it is not just a quote — it is a small lesson for the day. Perfect for morning motivation, WhatsApp status and social media captions.

## 🚀 Features

- 📅 **A new thought every day** — changes automatically with the date
- 📚 **76 thoughts** — Kalam, Gandhi, Vivekananda, Tagore, Buddha, Rumi, Einstein and more
- 🏷️ **11 categories** — Motivation, Life, Success, Wisdom and more
- 💡 **Meaning included** — a short explanation with every thought
- 🗓️ **Browse other days** — previous/next day and a week-at-a-glance strip
- 🔍 **Search and filters** — find thoughts by word or category
- ❤️ **Favourites** — save the thoughts that hit home
- 📤 **Share easily** — copy the text, share on WhatsApp, or **download a shareable image card**

## 🎮 How to Use

1. Open the page — today's thought is waiting for you.
2. Read the meaning, save it to favourites, or download the card to share.
3. Come back tomorrow for a fresh one.

## 🛠️ Tech Stack

| Part | Technology |
| --- | --- |
| Frontend | HTML, CSS, JavaScript (single page) |
| Data | Thought collection built into the page; the daily pick is chosen by date |
